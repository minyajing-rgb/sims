**Parent method:** `skills/sims-full-competitor-benchmark/SKILL.md`

## Purpose

This audit closes a gap left by the raw ADX matrix:

> A creative can run for a long time and still be a bad product promise.

For every Priority 8 representative creative, classify:

`Hook → Product Layer Promised → Real Product Support → Core Shown? → First-session Repayment → Promise-match Risk → Production Burden → What Ops Cat Can Test`

The audit does **not** infer spend, CTR, CVR, CPI, paid share or ROAS.

## Executive read

### Strongest promise-product fit
1. **Hay Day** — emotional decompression is delivered by the actual farm/ownership loop.
2. **My Perfect Hotel** — the sampled long-running card shows the actual top-down service/upgrade loop.
3. **Big Farm Homestead** — “welcome home” maps directly to a persistent owned farm/restoration asset.

### Highest promise-match risk
1. **The Cozy Florist** — sampled frame uses real-world flower craft imagery; the real game supports the fantasy, but the bridge to garden/shop gameplay must happen quickly.
2. **Gossip Harbor** — relationship-conflict opening is real to the story layer but can hide the merge core.
3. **Heartopia** — matching outfits are real product capability, but they are an identity/social layer rather than the first core verb.

## Product-by-product

### Gossip Harbor
- **OBSERVED:** representative card opens on relationship/casino conflict; no merge board visible in the sampled frame.
- **SOURCE:** real product = merge food/orders → restaurant repair/decor → story/mystery/relationships.
- **INFERRED:** story tone can repay the hook, but the merge core is not the same promise layer.
- **Risk:** HIGH.
- **Ops Cat:** if emotion opens the ad, show the real mow/clean interaction and persistent garden transformation by second 2–5.

### Township
- **OBSERVED:** “The #1 Farm Game” copy + prize/timer reward visual.
- **SOURCE:** product contains farming, town ownership, Match-3, expeditions, passes and collections.
- **INFERRED:** farm identity anchors the card, but prize/timer can overtake ownership if used as the only value.
- **Risk:** MEDIUM.
- **Ops Cat:** reward reveals are useful after the player understands what they are building.

### Hay Day
- **OBSERVED:** “After a long day, my farm is my peaceful place.”
- **SOURCE:** the real game delivers farming, decorating, trading, neighborhood and seasonal systems.
- **Interpretation:** strongest promise-product match in the set.
- **Risk:** LOW.
- **Ops Cat:** “my little garden / my quiet corner” can be the acquisition promise if the garden is already meaningful in the first session.

### Big Farm Homestead
- **OBSERVED:** “Build, grow, and relax” / “Welcome home, farmer.”
- **SOURCE:** restore/produce/orders + multi-farm ownership + story.
- **Interpretation:** “home” is stronger than generic “relax” because it maps to a persistent asset.
- **Risk:** LOW.
- **Ops Cat:** combine a low-friction action with a named owned place.

### The Cozy Florist
- **OBSERVED:** sampled Instagram card uses real-world flower craft imagery and “Create your own secret garden.”
- **SOURCE:** actual product = garden + flower shop + customization/social.
- **INFERRED:** the fantasy is truthful at a thematic level but not visually identical to installed gameplay.
- **Risk:** HIGH unless gameplay appears quickly.
- **Ops Cat:** real-world tactile inserts can be used only as a short hook; show actual game by second 2–5.

### Office Cat
- **OBSERVED:** copy stays close to “Office Cat Tycoon.”
- **SOURCE:** product = idle income → office/company upgrades → city growth.
- **Interpretation:** low promise mismatch; weak risk is that “cute cats” alone do not create long-term ownership depth.
- **Risk:** LOW-MEDIUM.
- **Ops Cat:** a mascot can make the loop readable, but the persistent garden/home must carry return value.

### My Perfect Hotel
- **OBSERVED:** sampled 25-second YouTube unit shows direct top-down hotel service/upgrade gameplay with no copy.
- **SOURCE:** actual loop = manual service → cash/tips → upgrades → staff automation → expansion.
- **Interpretation:** cleanest “show the loop” benchmark.
- **Risk:** LOW.
- **Ops Cat:** use as the first 3–5 second grammar, then add stronger ownership/identity.

### Heartopia
- **OBSERVED:** sampled TikTok card shows matching couple outfits.
- **SOURCE:** multiplayer, fashion, photography and UGC are real product capabilities.
- **INFERRED:** truthful capability, but not necessarily an immediate first-session payoff.
- **Risk:** MEDIUM.
- **Ops Cat:** identity/social creatives should be activated only after the corresponding feature is reachable fast enough.

## Cross-product principles

### 1. Promise layer must be explicit
Tag each creative:
- Core
- Ownership
- Story/Relationship
- Identity/Social
- LiveOps/IP

Do not evaluate “truthfulness” only at the theme level.

### 2. Five-second repayment rule
For cold acquisition:
- 0–2s: emotion / aspiration / light problem
- by 2–5s: real interaction
- by 5–10s: persistent before/after result

This is a **test hypothesis**, not an industry law.

### 3. Owned asset is the safest bridge
Strongest cross-title acquisition→retention bridge:
`emotion → real action → visible owned asset`

### 4. Creative production burden matters
For a lean studio, prioritize:
1. direct gameplay captures;
2. modular before/after edits;
3. reusable mascot/character shots;
4. only then bespoke drama, real-world craft or high-fashion social productions.

### 5. Trend/Cause boundary
This audit adds a UA/product evidence class. It does **not** upgrade any E0/E1 anomaly to E2/E3 because:
- no matched monthly creative time series;
- no source mix;
- no spend;
- no paid/organic split;
- no campaign-level attribution.

## Ops Cat test plan

| Test | Variants | Primary acquisition metric | Product-quality guardrail |
|---|---|---|---|
| Promise layer | Core / Ownership / Identity | CTR→CVR→qualified install | D1/D7 + promised feature reached |
| Repayment timing | gameplay at 2s / 5s / 8s | install CVR | tutorial drop / uninstall |
| Owned asset | reward only / before-after / player choice | qualified CPI/IPM | second-session ownership return |
| Production burden | direct gameplay / modular edit / bespoke narrative | winner rate per asset-hour | monthly creative throughput |
