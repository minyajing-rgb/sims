## Why this matters

The category question is not “what features does the game have?”

It is:

> **What does the player understand in the first 3 seconds, what becomes automatic by 10 minutes, what ownership exists by 30 minutes, and what is intentionally delayed until D1/D7?**

## Cross-product newbie pattern

### Stage 1 — Action before explanation
Best example: My Perfect Hotel.

### Stage 2 — First owned/managed object
Examples:
- hotel room;
- office room/company;
- farm;
- garden/shop;
- starter home.

### Stage 3 — Helper / automation
Examples:
- cleaner/receptionist;
- superintendent;
- production automation / staff.

### Stage 4 — Secondary logistics
Examples:
- toilet/utility;
- power/maintenance;
- production chain;
- inventory/storage;
- D.G./hobby progression.

### Stage 5 — Meta / social / LiveOps
Delayed until the player understands the owned space.

## Ops Cat FTUE target hypothesis

```
0–30s      Mow / Clean → visible transformation
30–90s     first resource + first reward
1–3m       first repair / ownership choice
3–5m       tool upgrade / helper preview
5–10m      helper + secondary production/logistics
10–20m     NPC/story + collection
20–30m     first light event surface / optional offer
D1–D3      second zone + recurring mission
D7         first meaningful seasonal event / pass test
```

This is an OWNER TEST HYPOTHESIS, not a competitor-observed fact.
