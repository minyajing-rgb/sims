Creative operating rules

Promise layer tag

Tag every asset as Core / Ownership / Story / Identity / LiveOps before judging truthfulness.

Repayment timing

Test real interaction at second 2 / 5 / 8 and read qualified install + D1/D7, not CTR alone.

Lean production order

Direct gameplay → modular before/after → reusable mascot shots → bespoke narrative/lifestyle only when justified.

Owned asset bridge

Emotion → real action → visible persistent garden/home → player choice.

Identity ceiling

Fashion/social/pet hooks are later layers unless they are truly reachable in first session.
