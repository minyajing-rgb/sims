# Art + Creative Test Plan v0.1

**Goal:** test the visual proposition before committing to a heavy production pipeline.

## 1. Test three art families

### A — Clean Cozy 3D
Current bright toy-like 3D baseline.

### B — Handcrafted 2.5D
Same layout/gameplay, but add:
- gouache/watercolor surface,
- painted foliage,
- hand-drawn signage,
- story props,
- softer material response.

### C — 2D Gameplay + 3D Hero Transition
- main playable scene uses 2D/2.5D,
- 3D/video appears only for unlock, travel, reward, or chapter change.

## 2. Keep the gameplay hook identical

For art testing, use the same:
- first 3 seconds,
- objective,
- cat,
- yard,
- reward.

Only change:
- rendering style,
- camera treatment,
- UI finish,
- amount of narrative detail.

Otherwise the test cannot isolate the art variable.

## 3. Core test creatives

### Creative 1 — Mow & Reveal
Overgrown yard → mowing → hidden object / flower / clue appears.

### Creative 2 — Before / After
Messy yard → satisfying restoration → personalized finished yard.

### Creative 3 — Story Hook
A simple action reveals an emotional object or neighbor story.

### Creative 4 — AI Personalization
“What kind of day do you want?” → different yard / task / story outcomes.

### Creative 5 — Travel Expansion
Backyard life → postcard / map → seaside micro-game.

## 4. Metrics

### Creative phase
- thumb-stop / 3s view
- CTR
- CVR
- CPI
- comment sentiment
- save/share rate where available

### Playable phase
- tutorial completion
- first action completion
- time to first visible transformation
- first 5-minute completion
- D1
- D3
- D7
- return-to-decorate rate
- story-choice interaction rate

## 5. Decision rule

Do not choose the most beautiful style.

Choose the style that gives the best combined score on:
- acquisition,
- comprehension,
- production cost,
- retention proxy,
- identity.

## 6. Suggested experiment order

1. Static image A/B/C
2. 8–15s video A/B/C
3. 30–60s playable prototype
4. Small paid traffic
5. Retention test
6. Only then commit to production art.
