# Gameplay Archetype Map v0.1

## 从轻到重，不把“Casual”和“Simulation”当成二选一

### Layer 0 — Satisfying Action
割草 / 清洁 / 切割 / 摆货 / 插花 / 做饭 / 打包 / 修理 / 收割。

要求：
- 3秒看懂
- 30秒有结果
- 1–3分钟完成一个小循环
- 能直接做广告素材

### Layer 1 — Light Management
Action → Reward → Upgrade → More Capacity → New Customer/Area。

这是 My Perfect Hotel / Eatventure 一类最有效的轻经营骨架。

### Layer 2 — Ownership
店铺 / 房间 / 花园 / 家 / 衣柜 / 宠物 / Collection。

这是从“玩一局”变成“这是我的东西”的关键。

### Layer 3 — Character & Story
NPC需求、租客、客人、关系、任务、章节。

用于情绪留存，不要在D0塞太多剧情。

### Layer 4 — LiveOps
Daily / Weekly / Season / Album / Collection / Event Shop。

### Layer 5 — Optional Midcore
轻Roguelite、战斗、地图探索、合作、轻竞争。

**只有核心经营已经成立后才加。**

# 关于“割草小游戏”

不建议第一版做一个和经营完全分离的“割草副玩法”。

更值得测试的是：

> **割草 = 经营生产链的一部分**

例：
1. 草地长满 → 玩家割草（爽感）
2. 割草掉落种子/材料/隐藏物
3. 清理后的地块可种植/装修
4. 收获用于订单/制作
5. 卖出后升级工具/解锁新区域
6. 新区域出现新的植物/宠物/NPC

这样割草既是Creative Hook，也是Core Action，不会变成后期没人玩的孤岛系统。

# 三种可验证产品骨架

## P1 — Casual-first Sim
Hands-on action → Idle/Management → Decor/Collection
- 最适合6个月验证
- 低内容风险
- Mobile/H5/小游戏最好适配

## P2 — Lifestyle Light Sim
Management → Home/Avatar/Pet/NPC → Season
- 适合12个月
- 品牌/IP价值高
- 美术资产压力中等

## P3 — Sim → Midcore
Management → Exploration/Combat/Roguelite → Guild/Competition
- 参考疯狂水世界的升级路线
- 适合核心数据已经证明后
- 不建议首发就做
