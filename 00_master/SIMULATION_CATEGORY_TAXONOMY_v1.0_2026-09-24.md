# Simulation / Management Genre Taxonomy v1.0

**Date:** 2026-09-24  
**Scope:** Mobile / H5 / Mini-game / Steam-PC  
**Purpose:** 建立统一的模拟经营品类语言，避免把“Cozy、经营、养成、建造、Life Sim、Idle、SLG前置模拟经营”混成一个大类。

---

## 0. 先统一三个概念

### A. Simulation / 模拟
模拟某种生活、职业、生产、经营、空间或社会系统。

### B. Management / 经营
玩家持续配置资源、时间、人员、产能、空间和目标，追求效率、扩张或更好的状态。

### C. Cozy / 治愈
**Cozy 是体验调性，不是独立玩法类型。**

Steam 也把 Cozy 作为情绪/主题标签；Life Sim、Management、Farming Sim、Shop Keeper、City Builder、Colony Sim 等才更接近玩法类别。

因此：
- Cozy Farming Sim ✅
- Cozy Shop Sim ✅
- Cozy Life Sim ✅
- Cozy Colony Sim ✅
- Cozy 并不自动等于轻度，也不等于女性向。

---

# 1. 市场一级品类

## 1.1 Farming / Agriculture
**核心幻想：** 种植、收获、加工、订单、农场扩建。

典型循环：
```
Plant → Wait/Produce → Harvest → Process → Order/Sell → Upgrade/Expand
```

典型长线：
- 土地扩张
- 新作物/动物
- 工厂/加工链
- 订单
- Collection
- 社交
- Seasonal LiveOps

代表：
- Township
- Hay Day
- My Garden Tale / 我的花园世界
- Stardew Valley
- Fields of Mistria

适合研究：
- 长周期内容生产
- 生产链
- LiveOps
- 社交
- Cozy ownership

---

## 1.2 Life Sim / Lifestyle Sim
**核心幻想：** “这是我的生活 / 家 / 人 / 关系 / 日常。”

核心模块：
- Avatar
- Home
- NPC relationship
- Hobbies
- Pet
- Collection
- Exploration
- Social / UGC

代表：
- Heartopia
- The Sims FreePlay
- Stardew Valley
- Fields of Mistria
- Petit Planet（趋势）

特点：
- 情绪留存高
- 可形成身份表达
- 美术资产量大
- 内容生产成本通常高于纯经营

---

## 1.3 Time Management / Service Management
**核心幻想：** 在有限时间内完成顾客服务、制作、排队、升级。

典型循环：
```
Customer → Task → Serve → Earn → Upgrade → Harder Customer / New Venue
```

代表：
- Cooking Diary
- Cooking Fever
- 时尚百货城
- Good Pizza, Great Pizza
- Good Coffee, Great Coffee

优点：
- Action 清晰
- D0容易理解
- 非常适合Playable / Video UA
- 可向剧情、装修、Collection扩展

---

## 1.4 Shop / Job Simulator
**核心幻想：** “我真的在做这份工作。”

常见动作：
- 上货
- 定价
- 收银
- 修理
- 烹饪
- 清理
- 打包
- 制作
- 开卡包
- 服务客户

代表：
- TCG Card Shop Simulator
- Supermarket Simulator
- Tiny Bookshop
- ReStory
- Good Pizza, Great Pizza

特点：
- 手上持续有事做
- Creator / Streamer传播强
- 非常适合做“动作本身就是内容”

---

## 1.5 Tycoon / Idle Management
**核心幻想：** 从小设施逐渐扩张成大型业务。

循环：
```
Do / Automate → Earn → Upgrade → Capacity ↑ → New Area → Repeat
```

代表：
- My Perfect Hotel
- Eatventure
- Office Cat
- Cat Snack Bar
- Rent Please!

特点：
- 入口很轻
- 系统容易模块化
- 适合Mobile
- 如果没有角色/空间/收藏，很容易同质化

---

## 1.6 Decor / Restoration / Makeover Sim
**核心幻想：** 从“乱/旧/破”变成“漂亮/温暖/属于我”。

核心动作：
- 清理
- 割草
- 修复
- 装修
- 摆放
- 换装
- Before / After

代表方向：
- Home / Garden restoration
- My Leisure Time
- Resortopia
- Ops Cat 当前原型方向

这是非常适合：
- Cozy
- satisfying
- before/after UA
- AI个性化空间
的品类。

---

## 1.7 City / Town / Base Builder
**核心幻想：** 从一个小区域成长成城市/社区/基地。

循环：
```
Resource → Build → Population/Capacity → New Production → Expand
```

代表：
- Township
- Timberborn
- City builders
- settlement builders

优点：
- progression可视化强
- 内容长线深

风险：
- 数值系统和内容量迅速变重
- 小团队容易失控

---

## 1.8 Colony Sim
**核心幻想：** 管理一群具有需求和行为的个体，让社区存活/繁荣。

代表：
- RimWorld
- Oxygen Not Included
- Timberborn

核心系统：
- 角色需求
- 工作分配
- 资源
- 环境
- 事件
- emergent story

研究价值：
- “系统自己生产故事”
- AI-native可以借鉴其事件/角色状态模型

不建议作为小团队首个Mobile项目的直接制作体量。

---

## 1.9 Pet / Creature / Nurturing
**核心幻想：** 照顾、养成、收集、陪伴。

模块：
- feeding
- care
- mood
- growth
- dress-up
- collection
- habitat

代表方向：
- virtual pet
- animal cafe
- pet collection
- aquarium / creature care

适合：
- Cozy
- 角色IP
- 情绪留存
- 轻量AI角色关系

---

## 1.10 Vehicle / Industrial / Professional Sim
**核心幻想：** 操作真实或半真实工具/机器。

代表：
- Farming Simulator
- Truck / train / flight sims
- cleaning / repair job sims

核心价值：
- 操作感
- 专业身份幻想
- PC长时长

对 Ops Cat 的借鉴：
不是做重模拟，而是学习“工具操作反馈”。

---

# 2. Hybrid Simulation / 融合型模拟经营

模拟经营已经越来越多被用作“前台低门槛”。

## 2.1 Sim + Puzzle
- Match-3
- Merge-2
- Sort
- Block
- Screw

用途：
- Casual core负责获量
- Sim meta负责ownership和长期目标

---

## 2.2 Sim + Roguelite / Combat
入口：
- 经营
- 采集
- 清理

后期：
- 战斗
- build
- equipment
- map progression

适合：
- Habby式轻入口长养成

---

## 2.3 Sim + RPG
经营外层接：
- 角色养成
- 装备
- 技能
- 副本
- guild

代表研究：
- Go Go Muffin
- Legend of Mushroom
- Heroes Don't Have Flash

---

## 2.4 Sim + SLG / 4X
常见结构：
```
Collect / Build / Manage
→ Character / Card
→ Alliance / Map / Competition
→ SLG
```

代表研究：
- Crazy Water World
- Lands of Jail
- Kingshot
- Whiteout Survival 类结构

这是“小玩法前台 → 重系统后台”的典型路径。

# 3. Mini-game / H5 特有分类

## 3.1 一动作经营
例如：
- 割草
- 清理
- 挖矿
- 收割
- 做饭
- 上货
- 搬运

目标：
- 3秒看懂
- 30秒反馈
- 1–3分钟循环

## 3.2 社交经营
- 偷菜
- 帮助
- 拜访
- 协作订单
- 排名
- gifting

## 3.3 经营 + 中度Meta
这是当前小游戏很重要的结构：
- 前期经营
- 中期卡牌/角色
- 后期SLG/合作/竞争

# 5. 对当前工作室最值得重点研究的五条赛道

1. **Hands-on Cozy Management**  
   Good Pizza / Good Coffee / Shop Sim 的“手上有事做”。

2. **Garden / Restoration / Decor**  
   割草、清理、修复、装饰、Before/After。

3. **Cute Idle / Tycoon + Ownership**  
   Office Cat / Rent Please / My Perfect Hotel。

4. **Lifestyle Light Sim**  
   Heartopia / 我的休闲时光 / 我的花园世界。

5. **Casual Front + Long Meta**  
   Habby类、疯狂水世界、Lands of Jail 等。

这五条赛道覆盖从 1–3分钟 session 到长期养成，是当前 `sims` 仓库的优先研究范围。
