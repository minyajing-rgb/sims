**Date:** 2026-09-24  
**Status:** CURRENT  
**Purpose:** 像 SparkPro 一样，按研究目的选样本，而不是做一个“综合Top榜”。

## 0. 研究组合总览

| Objective | Primary samples | What to learn |
|---|---|---|
| 美术 / 生活方式表达 | Heartopia / Resortopia / Good Pizza Great Pizza | 角色+空间资产、作者风格、截图传播 |
| 最轻核心循环 / UA | My Perfect Hotel / Eatventure / Good Pizza Great Pizza | 3秒看懂、30秒反馈、动作就是广告素材 |
| 长期经营 / LiveOps | Township / Hay Day / Animal Restaurant | 老产品底盘、活动承接、内容复用 |
| Mobile轻经营+Ownership | Rent Please / Office Cat / 我的花园世界 | 房间/社区/角色/装修如何给idle加留存 |
| 小游戏轻→中度 | 疯狂水世界 / 我的花园世界 / QQ经典农场 | 小游戏入口、社交、建造、再向卡牌/中度扩展 |
| PC自然量 / Creator | TCG Card Shop Simulator / Supermarket Simulator / Waterpark Simulator | “手上有事做”、主播视频标题天然成立 |
| 高口碑Cozy深度 | Fields of Mistria / Stardew Valley / Tiny Bookshop | NPC、世界、系统咬合与“太浅”的边界 |
| 未来Life Sim上限 | Heartopia / Paralives / Petit Planet | 12–18个月后的角色/住房/生活方式资产上限 |

## 1. 当前最值得逐帧拆的 8 款

### Heartopia
- 看：Stylized 3D、avatar/home/pet/hobby、UGC、社交。
- 不抄：开放世界资产规模。
- 目的：定义12–18个月“生活方式层”上限。

### Good Pizza, Great Pizza
- 看：核心动作、顾客表达、作者美术、低成本高辨识度。
- 不抄：题材本身。
- 目的：定义“动作本身就好玩”的最低成本标准。

### My Perfect Hotel
- 看：跑动、清洁、收钱、升级、扩建的超直白Loop。
- 不抄：广告过重体验。
- 目的：定义Casual-first原型。

### Office Cat
- 看：isometric room modularity、可爱IP、idle+装修。
- 不抄：普通cute tycoon同质化。
- 目的：定义中小团队Mobile资产生产方式。

### 我的花园世界
- 看：种植→花艺→订单→庭院→宠物/换装→社交；现实鲜花钩子。
- 不抄：活动/系统过早堆叠。
- 目的：定义女性向Lifestyle+经营的本土成功结构。

### 疯狂水世界 / Wild Water World
- 看：轻经营入口如何逐步接卡牌/中度系统；小游戏→App出海。
- 不抄：一开始就上SLG深度。
- 目的：定义“轻→中”的升级路径。

### TCG Card Shop Simulator
- 看：店铺经营+稀有掉落+收藏+creator传播。
- 不抄：第一人称PC控制方案到Mobile。
- 目的：把“经营”和“随机惊喜”结合。

### Fields of Mistria
- 看：角色关系、世界氛围、低资产风格下的内容密度。
- 不抄：Pixel风格本身。
- 目的：研究高口碑Cozy为什么不靠昂贵3D。

## 2. 如果只做三款“结构拼接”研究

不是做copy，而是分别拿一层：

1. **My Perfect Hotel** → Casual Core / UA
2. **Good Pizza Great Pizza** → Hands-on + Character + Art identity
3. **Heartopia / 我的花园世界** → Ownership / Lifestyle / Long-term Meta

组合成：

> Satisfying Action → Earn → Upgrade → Decor/Collection → Character/Lifestyle → LiveOps

## 3. 对“割草”的处理

把割草当：
- Creative Hook
- Core Action候选
- Resource production
- Map cleaning / reveal
- Decoration unlock

而不是独立孤岛小游戏。

例如：

`割草 → 掉落种子/素材 → 清出地块 → 种植/装修 → 客人订单 → 收入 → 升工具/开新区域`

这会同时保留 Casual 的CTR潜力和 Sim 的长期progression。
