# Public Repository Content Boundary

The repository `minyajing-rgb/sims` is currently public.

Therefore this repo should contain:
- product research,
- gameplay design,
- art direction,
- public benchmark data,
- non-confidential visual references,
- implementation plans,
- public prototype links.

Do **not** place here:
- private client data,
- contracts,
- credentials,
- personal private-chat content,
- unreleased third-party confidential material,
- passwords / tokens / account identifiers.

Cross-conversation consolidation must be project-only and privacy-filtered.
