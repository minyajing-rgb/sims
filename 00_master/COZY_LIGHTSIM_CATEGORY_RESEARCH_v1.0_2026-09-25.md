# Cozy / Light-Sim / Casual-to-Long-Meta Category Research v1.0

**Date:** 2026-09-25  
**Market:** US-first, Global-secondary  
**Parent Skill:** `skills/sims-full-competitor-benchmark/SKILL.md`

## 1. Category definition

This research category is not one genre. It is a product architecture family:

```
Low-friction Action
→ Visible Transformation
→ Persistent Ownership
→ Progression / Automation
→ Collection / Story / Social
→ Reusable LiveOps
→ Long-term Monetization
```

Relevant archetypes:
1. Service / Time-management: My Perfect Hotel
2. Idle Tycoon / Modular Management: Office Cat
3. Farming / Restoration / Production: Big Farm Homestead
4. Cozy Niche Lifestyle: The Cozy Florist
5. Evergreen Mature Farming: Hay Day / Township
6. Narrative Meta Machine: Gossip Harbor
7. Lifestyle / Social Ceiling: Heartopia

## 2. Six category questions

### Q1 — 3 seconds: what should the player do?
Strongest low-friction pattern:
- one verb;
- direct movement/tap;
- visible before/after;
- reward within seconds;
- no abstract system explanation before action.

Best references:
- My Perfect Hotel: manual service before explanation.
- Office Cat: visible room/build/upgrade grammar.

Ops Cat hypothesis:
`Mow/Clean → grass/garbage disappears → reveal → resource → visibly improved owned space`.

### Q2 — first 30 minutes: what should unlock?
Best staged pattern:
1. Core action
2. First reward
3. First upgrade
4. First ownership choice
5. First helper/automation
6. Secondary logistics
7. First meta surface
8. First event/offer only after value is understood

Historical My Perfect Hotel evidence:
- cleaner option T+1:46;
- first rewarded cash ad T+2:19;
- cleaner hired T+4:20;
- toilet/utility T+5:00;
- receptionist T+9:26;
- hotel level 1 T+11:29;
- No Ads T+11:50.

Important: timing is historical evidence, not current 2026 truth.

### Q3 — D7+: what keeps the game alive?
Long-term value is usually not “more of the first action” alone.

Durable layers:
- persistent owned place;
- production / capacity growth;
- area expansion;
- collection;
- NPC/story;
- pet/avatar identity;
- social;
- pass/event;
- long-term economy sinks.

Best reference combination:
- Hay Day: evergreen production.
- Big Farm Homestead: ownership → regions → season/pass/collection.
- Gossip Harbor: reusable event shell + story cadence.
- Heartopia: identity/social ceiling.

### Q4 — how much art is enough?
Three different needs must be separated:
- D0 readability;
- brand differentiation;
- monthly production throughput.

Best references:
- My Perfect Hotel: D0 readability.
- Office Cat: modular reuse.
- The Cozy Florist: strong niche fantasy + before/after.
- Heartopia: art/content ceiling, not MVP cost reference.

Ops Cat target:
**70–90% commercial readability + 10–30% authored watercolor/gouache detail.**

### Q5 — how heavy should LiveOps be?
Use four levels:

- L0: login / simple mission / bonus
- L1: event currency + milestone + themed reward
- L2: pass + collection + leaderboard / mini-game
- L3: bespoke map / major story / IP / unique gameplay

For a small first product:
- mostly L0/L1;
- one reusable L2 mother engine;
- avoid L3 before retention is proven.

### Q6 — what can a small team sustain?
The correct unit is not headcount. It is **content work-types per release**.

Lean model:
- reusable core;
- modular environment;
- config-driven LiveOps;
- short modular story;
- low-frequency client updates;
- high-frequency server/config events;
- direct gameplay / modular creative production.

Best reference:
- Office Cat / My Perfect Hotel for production efficiency.
Counterexample:
- Heartopia-scale lifestyle breadth.

## 4. Media research rule

Public videos and Store media are evidence sources, not decorative embeds.

Research chain:
```
Source URL
→ Version / Date / Market
→ Timestamp Map
→ Evidence Frame IDs
→ FTUE / Core / Meta observation
→ Creative/Product comparison
→ Product decision
```

For local/offline HTML:
- no iframe;
- no remote image autoload;
- no third-party permission popup;
- only explicit source links.

For online/browser research:
- open source in a new tab when needed;
- record timestamp and what the source proves;
- do not rehost full copyrighted video.

## 5. Category conclusion

The most defensible first-product architecture is:

> **Hyper-readable Action + Persistent Ownership + One long-meta spine + One reusable LiveOps engine.**

Do not start with:
- pure mowing only;
- full Heartopia-like open world;
- multiple bespoke mini-games;
- heavy social before ownership matters;
- L3 LiveOps before D7 retention is proven.
