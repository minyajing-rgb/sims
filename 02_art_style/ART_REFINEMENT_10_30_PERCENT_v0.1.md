# Art Direction — 10–30% Handcrafted Refinement v0.1

## Problem

The current bright toy-like 3D style is:
- readable,
- cheerful,
- easy to understand,
- suitable for casual audiences.

But it risks:
- looking generic,
- blending into the current “AI cute/cozy” visual field,
- producing high clicks but weaker long-term identity,
- feeling decorative rather than lived-in.

## New rule

Do **not** replace the full style.

Refine only **10–30%** of the visible language.

### Keep 70–90%
- bright daylight,
- warm saturated garden colors,
- readable 3D forms,
- friendly cat character,
- clear interactable props,
- simple mobile UI,
- high-contrast action results.

### Change 10–30%
Add a visible authorial hand:
- gouache / watercolor brush breakup,
- hand-painted edge masks,
- imperfect floral clusters,
- paper / canvas texture,
- illustrated maps and postcards,
- handwritten signs,
- small personal objects,
- local travel motifs,
- story clues embedded in the environment,
- slightly less plastic PBR response.

## Narrative visual design

Every main screen should contain **one story object**.

Examples:
- old photo behind the bench,
- postcard from a previous owner,
- neighbor's forgotten gardening glove,
- cat toy under the grass,
- handwritten recipe,
- shell collected on a trip,
- damaged sign that gets restored.

This turns a generic task into a remembered scene.

## Recommended style target

> **Cozy toy readability + hand-painted editorial surface + lived-in environmental storytelling.**

Not:
- full realism,
- full watercolor abstraction,
- heavy painterly noise,
- hyper-detailed UE look.

## Character treatment

Ops Cat remains the anchor.

Refine by:
- slightly more hand-painted fur breakup,
- less uniform plastic gloss,
- more costume stitching / fabric texture,
- situational props,
- stronger pose storytelling,
- local-travel outfit variants.

## Environment treatment

Use:
- readable 3D massing,
- painted decal / texture overlays,
- illustrated signage,
- slightly exaggerated flowers and vegetation,
- small asymmetries,
- before/after transformation that is obvious at a glance.

## UI

UI can remain clean and digital.

Add handcrafted detail only in:
- chapter cards,
- quest cards,
- postcards,
- collection album,
- map,
- story log.

This prevents the whole screen from becoming noisy.
