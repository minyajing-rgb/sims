# Art Style Map v0.1

**Rule:** 先研究“美术是否帮助自然量/截图传播/素材生产”，再决定玩法复杂度。

## 1. Stylized 3D Cozy World
**Benchmarks:** Heartopia / upcoming Petit Planet / Paralives  
**Strength:** 角色、住宅、服装、宠物、社交资产全部可视化；UGC和截图传播强。  
**Risk:** 资产量、动画、镜头、交互成本高；中小团队最容易把“世界做大但可玩内容不够”。  
**Use for us:** 作为12–18个月上限，不作为第一个6个月版本的起点。

## 2. Isometric Hand-painted / Cute Management
**Benchmarks:** Office Cat / Rent Please / 我的花园世界  
**Strength:** Mobile信息密度高；房间/建筑/人物都可重复模块化生产；非常适合LiveOps换皮和扩建。  
**Risk:** 很容易变成普通“国产Q版经营”，缺品牌辨识度。  
**Use for us:** 高适配。建议把普通Q版升级为 **editorial watercolor/gouache + cleaner UI + premium material**。

## 3. Illustrated 2D / Strong Author Style
**Benchmarks:** Good Pizza Great Pizza / Animal Restaurant / Resortopia  
**Strength:** 成本可控、辨识度高、容易形成IP；素材与游戏资产可以共用。  
**Risk:** 如果经营操作太弱，会变成“漂亮但没事做”。  
**Use for us:** **优先测试方向之一。**

## 4. Functional First-person 3D Job Simulator
**Benchmarks:** Supermarket Simulator / TCG Card Shop Simulator / Waterpark Simulator / ReStory  
**Strength:** 玩家一秒理解动作；天然适合YouTube/TikTok/主播；美术不是主要成本。  
**Risk:** Mobile触控和长线LiveOps需要重新设计；审美品牌性弱。  
**Use for us:** 值得借“手上有事做”的交互，不一定照搬第一人称。

## 5. Pixel Cozy
**Benchmarks:** Stardew Valley / Fields of Mistria  
**Strength:** 内容密度高、资产成本相对可控、PC玩家接受度高。  
**Risk:** 赛道极拥挤；与当前品牌审美并非最强匹配。  
**Use for us:** 做系统参考，不作为首选视觉方向。

## 6. Illustrated Survival / Post-apocalypse Isometric
**Benchmark:** 疯狂水世界  
**Strength:** 题材冲突强，建造前后对比强，容易与战斗/卡牌/SLG接轨。  
**Risk:** 一旦转中度，数值、系统、运营成本快速上升。  
**Use for us:** 用于研究“轻经营→中度”路径，不直接照抄题材。

# 首轮建议只做3套视觉Prototype

### A. Premium 2.5D Isometric
- 法式水粉/水彩质感
- 轻矿物/珠光材质
- 大留白、清楚轮廓
- 高级家居/生活方式
- 角色比例偏时尚插画，不做幼态大头Q版

### B. Stylized Light-3D
- 小范围可走动
- 店铺/花园/住宅模块化
- 人物和宠物可换装
- 只做一个block，不做开放世界

### C. Illustrated 2D Hands-on
- 直接操作物件：割草、插花、烹饪、整理、清洁、打包
- 每个动作有ASMR/satisfying反馈
- 用2D层级、骨骼、shader降低资产成本

**第一轮不是选“最好看的”，而是测：**
1. CTR / CVR
2. 玩家是否一眼看懂在干什么
3. 截图传播性
4. 单个新场景的生产成本
5. 一个月能不能稳定产出新内容
