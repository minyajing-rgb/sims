# Ops Cat Bright Life — Project Charter v0.1

## 1. Opportunity

### Market
US-first cozy / casual-management / light-simulation.

### Product thesis
**Casual acquisition hook + satisfying core action + light simulation ownership + AI-personalized narrative.**

### User promise
A player should quickly feel:
1. I know what to do.
2. My action visibly changes the space.
3. This place is mine.
4. The game reacts to my preferences.

## 2. Core loop

```
Mow / Clean / Repair
→ Collect
→ Upgrade Tool / Capacity
→ Decorate / Improve Owned Space
→ Unlock Area / Neighbor / Story
→ New Action + New Visual Transformation
→ Repeat
```

## 3. Initial vertical-slice scope

- 1 backyard
- 3 visual states: messy / improving / beautiful
- 4 micro-zones
- 3 core actions: mow / clear / decorate
- 2–3 tools
- 15–30 decoration items
- 3 reusable NPC archetypes
- 1 collection page
- 1 lightweight event hook
- bounded AI dialogue / task framing only

### Explicitly out of scope for G0–M1
- open world
- heavy multiplayer
- large UGC platform
- large pet system
- multiple concurrent event engines
- MMO-like persistent social state
- travel world

## 4. Why us / wedge

1. **Visible transformation** with high mobile readability.
2. **Ownership** instead of pure level-clearing.
3. **10–30% authored visual layer** to avoid generic toy-like AI-cute sameness.
4. **AI changes the world framing**, not only chatbot text.
5. **Lean modular production envelope** informed by Office Cat / My Perfect Hotel / Big Farm evidence.

## 5. Retention thesis

### D1
Return to complete an unfinished visible transformation / tool or decoration goal.

### D3
A second system or micro-zone broadens the loop without changing the core grammar.

### D7
Identity / collection / first reusable LiveOps wrapper begins to matter.

### D30
Persistent owned space + collection + recurring event / narrative wrapper + optional social/community return layer.

## 6. Monetization thesis

Order of exposure:
`Core value → Tutorial Release → Rewarded Utility → Premium Flexibility → Recurring Pass / Collection / Event Value`

Monetize:
- optional resource acceleration
- capacity / convenience
- event/pass value
- decoration / identity
- collection completion support

Do not monetize by making the first core loop intentionally broken.

## 7. Launch / test thesis

- US-first
- iOS / Android measured separately
- paid UA, owned/community CRM and organic/store kept as separate acquisition layers
- external benchmarks are REFERENCE only
- Owner KPI targets must be explicitly locked before Soft Launch

## 8. G0 decision required

Approve only:
- 6-week vertical slice
- test instrumentation
- limited art/content budget
- no full production commitment yet
