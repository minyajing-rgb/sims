# Ops Cat Project Initiation Decision v0.1

## Decision

**CONDITIONAL GO — approve G0 Project Initiation and a bounded 6-week Vertical Slice.**

Do **not** approve full production, large UA spend, open-world/social scope, or multi-engine LiveOps yet.

## Why GO

The current research is sufficient to support a bounded prototype:
- Market and benchmark coverage is broad.
- Core/ownership/visual-transformation thesis is specific.
- Lean-studio benchmark evidence exists.
- US-first value-market evidence exists across multiple relevant products.
- Monetization, LiveOps and production risks are known well enough to instrument rather than guess.

## Why CONDITIONAL

The following are not yet owned evidence:
- Ops Cat D1/D3/D7/D30
- US CPI / Store CVR / source mix
- payer / IAA quality
- exact content production cost
- asset-hours / event
- own event completion / CRM reactivation
- full-team throughput

## G0 exit criteria

G0 is complete when:
1. Charter locked.
2. Vertical slice scope locked.
3. KPI formulas locked; Owner Target can remain TBD only where no own baseline exists.
4. LiveOps P0 engine list locked.
5. Prototype Test Plan locked.
6. Kill criteria signed.
7. 6-week WBS has Owner / Due / Acceptance.
8. Instrumentation list approved.

## Recommendation for current product scope

### Build
- Backyard only
- Mow / Clear / Decorate
- 3 visible states
- 4 micro-zones
- small NPC/story layer
- simple tool progression
- one collection hook
- one reusable event hook
- bounded AI personalization

### Do not build yet
- travel world
- multiplayer community
- multiple heavy event engines
- large pet system
- open world
- external IP
- physical reward fulfillment
- deep UGC

## Funding logic

Use staged capital:
- G0/M1: prove action + transformation + ownership.
- M2: prove first 30m and production repeatability.
- M3: prove operation/data/content runway.
- G4+: only then test US paid acquisition at meaningful scale.

## Next review

After M1 Vertical Slice, answer:
- Is the action satisfying?
- Is the transformation obvious?
- Is ownership meaningful?
- Does AI add value?
- Can the art/content pipeline repeat within the chosen team envelope?
- Is there a credible reason to continue to M2?
